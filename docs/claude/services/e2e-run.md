## In-game E2E run (`IE2eRunService` / `SelfTest/E2e/E2eRunService`)

Moved verbatim from `Echokraut/Services/CLAUDE.md` (2026-11-25, size budget).

Unattended in-game E2E run, **dev loads only** (`IsDev`). Request `pluginConfigs/Echokraut-e2e/request.json` (polled every 2 s, deleted on read), state `state.json` (atomic, survives reloads: the running stage is restarted, never counted), log lines `EKTEST <id> <stage> start|pass|fail|skip|progress …` + `EKTEST <id> done p/f/s <report>`, remote host scrubbed to `<remote>`. Stages in `E2eCatalog` (preconditions, checks, chat-hook, backup, reset, first-time, checks:local, engine, scenarios, remote, checks:remote, always cleanup, opt-in restore); `remote` (`RemoteStage`) = stop local via `E2eSelfReload.StopEnginesAsync` (port free, nothing tracked) → `IBackendService.SwitchInstanceTypeAsync(Remote, remoteUrl)` (**the Backend tab's Local/Remote/None buttons use the same method**: leaving Local stops the local instance first) → voices → backend/generation/pipeline checks → game voice (D2 opt-in via `E2eOptions`, off again at stage end): `GameVoiceCheck`, then `E2eGameVoiceGeneration` (NPC from `IGameVoiceReferenceService.SampleVoicedNpcNameAsync` — own token, one epoch, text index only —, `RankAsync`, self-test line under that NPC's name, asserts `ReferenceSource == GameVoice`, deletes clip row + new character by id), parts `remote:<part>`; `engine` loops over the requested sub-engines (switch, start, `E2eEngineWait`, generation + pipeline check), each reported as `engine:<id>`, switches back to the last passed one (mark `engine-active`), which `scenarios` needs (`E2eStage.UnmetNeed`); `scenarios` runs the sub-scenarios in `E2e/Scenarios/` (continuation, queue-order, epoch-cancel, mute, then B7 below, chat-fc among them), each reported as `scenarios:<id>` via `E2eContext.ReportPart`, options through `E2eOptions` (`touchedOptions`); `first-time` empties `installRoot` (marker first, `IE2eInstallHost`), installs (request `testWrapper`: the dev zip from `tools/e2e/push-test-wrapper.sh` via `StartInstall(testWrapper: true)`), waits on a polled predicate and checks the listener on the engine port lives under the root (`GetExtendedTcpTable`); shares `ISelfTestRunGate` with `/ektest`. **Destructive** `backup`/`reset`: phase A in `BackupStage` (stop engine, port free, `SuppressSaveOnDispose`, touch own DLL → reload), phase B in `E2eStartupReset` (Plugin ctor before `GetPluginConfig`: backup + manifest + `restore.ps1`, then wipe except `selftest\`). The config stays an E2E config until a restore: **live** through the opt-in stage `restore` (`ExplicitOnly`, `RunsAfterAbort`; same self-reload via `E2eSelfReload`, the ctor checks every backup hash before the wipe and copies back) — `tools/e2e/restore.sh --live` or `start.sh --restore` — or `restore.ps1` with the game closed (fallback). Started from the Mac: `tools/e2e/start.sh`, `watch.sh <id>`, `fetch-report.sh <id>`. Plan + results: `docs/plans/ingame-e2e.md`; how to run it: `docs/plans/ingame-self-test.md` › Automation. Stage `cleanup` (`CleanupStage`, `AlwaysRuns` + `RunsAfterAbort`, before `restore`): only on an E2E config from `reset-done` on — restores `touchedOptions`, forces the game-voice opt-in off, deletes leftover `createdIds` (`wav:` only under `installRoot`, `clip:`, `character:<name>`) and every `Echokraut Selftest` character; the run service's `Finish` warns (`run warn` before `done` + chat) when the run ends on the E2E config. **Telemetry (B2)** in `state.json` › `telemetry` and the report: `E2eFrameMonitor` (fed by `Tick` every frame) records windows; ops `install` (first-time), `stop` (engine-stage baseline: stops the first-time engine once, `nvidia-smi` VRAM of the game alone), `switch:/start:/ready:<engine>`; a frame > 1000 ms = freeze → that part fails; per engine `/health` device, idle vs generation frames + GPU (`NvidiaSmiGpuProbe`, no console window), VRAM over baseline, install-root size, `.venv*`, `f5_tts` in `.venv` before f5 (fails f5 unless the run started on f5), underruns (`IAudioPlaybackService.UnderrunCount` delta around the pipeline check). **Engine options + install files (B3)**, `EngineStage.Options.cs`: parts `options:qwen-temperature` / `options:pocket-layers` (same setters as the UI → restart → ready → the installer's `Mode:` line in `EchokrautLocalInstaller.log` must carry the value, via `E2eInstallerLog`), `files:voice-pack` (`E2eVoicePackFiles`), `files:installer-log` (mojibake, NDJSON `key`, German text); a failed option step puts the originals back (marks, not `E2eOptions`: nested config). ⚠ A dev build installs the installer `main` on GitHub names — before that push ELI-1.3.1.0, which drops the Qwen/Pocket options. **Wrapper HTTP (B4)**, `Stages/WrapperHttpStage*.cs` (stage `wrapper-http`, after `engine`, same dependency as `scenarios` via `EngineStage.ActiveEngineUnmet`): talks to the running engine directly through `EchokrauTtsWrapperHttp` (`IE2eWrapperHttp`: `/tts` with the plugin's own `BuildTtsPayload`, headers `X-Cache`/`X-Job-Id`, `/health` › `response_cache`, `/jobs/{id}`, `/cancel/{id}`, `GET /`) and counts `tts request start` in the installer log (`E2eInstallerLog.TtsStarts`/`GenerationOf`/`TtsDone`, via `IE2eWrapperLog`). Parts `wrapper-http:cache` (miss → hit same bytes → bypass → hit, pair → miss + shared, counters exact, test page sends `no_cache`), `:cancel` (two miss + shared pairs: pair one, 3 sentences — one `/cancel`, the other client gets the clip to the end, generation `done` + `tts request done`, waited up to `RunToEndWait` 3 min; pair two, 10 sentences — both cancelled → `cancelled`, no `tts request done`, `running` 0, GPU drop judged only on cuda with ≥ 20 % load; same text again = miss. ⚠ One test sentence is ~23 s of XTTS audio: keep pair one short), `:vcm-regenerate` (throwaway `Echokraut Selftest` character + clip, `GenerateForVoiceClip` twice → 2 starts, bypassed +2; traces in `CreatedIds` first), `:repeat-hit` (`IBackendService.GenerateVoice` without `NoCache` twice → 1 start, hit, second first bytes ≤ 300 ms). Texts carry the run id (no hit from an earlier run). Skips on a wrapper without `response_cache` in `/health`. ⚠ Needs a CUDA engine active for the GPU judgement: run with `--engines xtts` (all six end on moss/CPU). **Own windows (B5)**, `Stages/UiStage.cs` + `UiStage.Sweep.cs` (stage `ui`, after `scenarios`, needs `first-time`, E2E config only): drives the windows through `E2eUiDriver` → `IOwnedWindowsService.Probe` (the window manager answers on the framework thread; texts read from the ATK tree by `Windows/E2eUi/AtkTextCollector`), judgements in `E2eUiChecks` (unit-tested). Parts `ui:commands` (`ICommandManager.ProcessCommand`: `/ek` `/ekconfig` `/ekfirst` `/ekdata` open + close their window, the seven `/ekt*` toggles flip and flip back), `:alias` (`/echokraut` registered — the tester checklist `inst-cmd` names it), `:backend-reopen` (Backend tab labels = every `Loc.S(key)` shown, identical after close + reopen; no remote field in Local, engine-only options per `EngineOptionScope`), `:engine-dropdown` (opened list read top to bottom = `TtsEngineAvailability.ForConfig`, the same source as the builder; none cut off), `:wizard` (`/ekfirst` on a finished config: Back to step 0, Remote → only the EK remote section, "Test connection" against the configured URL → "Connection successful", Next → summary; mode put back in `finally`), `:sweep` (every `IE2eSweepable` step of config, VCM (+ the detail window its first row opens) and Game Data Tools under `E2eFrameMonitor` op `ui-sweep`; a step error, a window that closes or a frame > 1000 ms fails), `:clamp` (pushed 80 % off bottom-right and top-left → ≥ 50 % per axis visible), `:loc` (non-English client: a seen text that is a `Loc` key with a different or no translation), `:changelog` (last: `LastSeenChangelogVersion` = `IChangelogService.PreviousVersion()` → self-reload (`E2eSelfReload`, phase unchanged, marks `ui-changelog*`) → popup opened by itself, title + subtitle `Echokraut <version>`, only this version unseen, no wizard → its "I've read it" step → reload → neither popup nor wizard within 10 s; the engine is waited for after each reload). `first-time` also reports `first-time:auto-open` (the wizard opened by itself after the reset reload). Sweep steps never change a setting (user decision 2026-11-25). **Game voice (B6)**, `Stages/GameVoiceStage.cs` + `GameVoiceIndexStage.cs` (hard constraint unchanged: only through `IGameVoiceReferenceService`, opt-in via `E2eGameVoiceGeneration.EnableOptIn`/`RestoreOptIn` — shared with `remote` —, same NPC, in memory). Every game-voice part runs inside `E2eAudioFileWatch` (snapshot before/after + `FileSystemWatcher` over install root, `pluginConfigs`, `%TEMP%`; any new/changed audio file fails the part, paths labelled `<install>\…`). Parts: `game-voice:engine-<id>` from **inside the engine loop** (`EngineStage` `gameVoice` hook, only when `game-voice` is in the run, only after the engine passed): `/health inline_reference` → expected availability (`E2eGameVoiceChecks.ExpectedAvailability`: true → Available, else ServerUnsupported — MOSS-ONNX has it, MOSS-PyTorch not), one line of the same NPC (`EngineNpcMark`, ranked once) with GameVoice resp. VoicePack. Stage `game-voice` (after `wrapper-http`, needs the active engine like `scenarios`): `:first-line` (two NPCs from `SampleVoicedNpcsAsync(lang, 2, unindexedOnly)`, `GameVoiceRankOnConversationStart` on, the first line must already be GameVoice; quick/total ms from `IGameVoiceReferenceService.PairRanked` via `E2eRankRecorder`), `:character-field` (`GameVoiceNpcOverride.Apply` `-` → VoicePack, own token → GameVoice, empty → GameVoice; dictionary restored), `:alias` (local alias disabled → VoicePack, assigned to its English owner → GameVoice with no `PairRanked`; `ExportAliasesForRepo` judged by `JudgeAliasExport` against the embedded resource). Opt-in stage `game-voice-index` (`ExplicitOnly`): `:abort-resume` (fast batch cancelled after 5 pairs twice, second run's up-to-date ≥ first's), `:whisper` (3 pairs, every `PairRanked.WithAsr`), `:full` (whole fast batch + `DetectVoiceChanges` when `/health speaker_embedding`, matching report judged), `:splits` (DE: Y'shtola 06100, Hydaelyn 06000, no Alphinaud/Thancred), `:unseen-npc` (an NPC no part met speaks GameVoice without ranking); frames op `game-voice-index:<label>`. ⚠ `:splits` needs `--engines xtts` (speaker encoder). ⚠ **Deploy after a KamiToolKit bump:** copy the whole dependency set into the dev folder (`KamiToolKit`, `Echotools.UI`, `Echotools.Logging`, `EchoScd`, then `Echokraut.dll` last — its write triggers the reload); `Echokraut.dll` alone against an older `KamiToolKit.dll` fails with a `TypeLoadException` and the request is never read (measured 2026-11-25).
**Scenarios (B7)**, `Scenarios/` (order in `E2eCatalog.Scenarios`): `phonetics` (correction for the first 4-letter word of the test sentence added → changed → deleted through `INpcDataService`; the queued `VoiceMessage.Text` must carry the replacement), `voice-reassign` (throwaway speaker gets another fitting non-narrator voice **from its own `npc.Voices`** — a voice outside that list reads as unfitting and `EnsureFittingVoice` re-rolls it — via `SaveCharacter`; next line and the one after "reload voices" use it; lines go as `AddonTalk` — `VoiceTest` maps to no character cache (`NpcDataService.ListForSource`), so every VoiceTest line is a new speaker with a random voice), `reload-voices` (the button's calls via `VoiceReload`: same voice keys, none twice), `narrator` (pick a non-default voice → nameless line (`speakerName: ""`) uses it → **self-reload mid-scenario** (marks `narrator`, `narrator-pick`, `narrator-original`; the stage restarts and keeps its done parts) → pick survived → unpicked → `Narrator.wav` → picked but voice disabled → `Narrator.wav`; `NarratorVoicePolicy.Resolve` asserted at each step, original pick + enabled state restored), `chat-fc` / `chat-channels` / `local-save` share `E2eChatLines` (print, wait, `Record` once per id, `RemoveTraces`); `chat-channels` prints per channel (Say … NoviceNetwork) with its option on (queued) and off (not queued within 4 s); `local-save` prints the same FC line twice: first generated + WAV, second `LoadedLocally` and played. `volume`: the game's `SoundVoice` slider (`IE2eGameSound`/`GameConfigSound`, set on the framework thread) at 100 and 50, while each line plays `IAudioPlaybackService.ChannelVolume` (BASS `ChannelGetAttribute(out float)` — float readback only) must equal `VoiceMessage.Volume` (polled up to 5 s: the queue marks the entry playing before `PlayStream`/`SetVolume`), ratio ≈ 0.5; the original slider is listed as `gamecfg:SoundVoice=<n>` in `CreatedIds` and `CleanupStage` puts it back after a crash (the game setting is not in the plugin backup). `bubble` (passive, `VoiceBubble` + `VoiceBubblesInCity` on, ≤ 2 min for an `AddonBubble` line, none = skip), `harvest` (`RunAsync` with `QuestType.None` only — non-quest dialog; the event-quest filter found 0 dialogs in a DE client; clip rows of the client language must rise), `alltalk-off` (last: `ITtsVoiceSyncService.SwitchEngine(Alltalk)` → EK not running, ports closed, VRAM −500 MiB when `/health` said cuda; then back to EK, `StartInstance`, ready — the stages after need it). Numbers in details are formatted invariant (DE client: no decimal comma in EKTEST lines). ⚠ A stage list with `scenarios` must also list `checks:local` (its need) — without it `scenarios` reports `skip needs checks:local (not run)` after a full install (run 20261125-220140).

Mixed wrapper state (B8) and wrapper CLI cases (B10): `docs/claude/services/e2e-run-wrapper.md`.
